# 🐝 TaskHive — Smart Task Management Dashboard

**Organize tasks. Track progress. Get things done.**

TaskHive is a modern, responsive task management dashboard built to help users organize their daily tasks, manage projects, monitor deadlines, and track productivity through a clean and intuitive interface.

## ✨ Features

- 📊 **Dashboard Overview** — View total, in-progress, completed, and overdue tasks.
- ➕ **Task Management** — Create, edit, and delete tasks.
- 🔄 **Status Tracking** — Update task progress and completion status.
- 🔍 **Search and Filter** — Find tasks and filter them by status.
- ↕️ **Task Sorting** — Organize tasks using available sorting options.
- 📅 **Deadline Management** — Set due dates and identify overdue tasks.
- 📁 **Project Management** — Create and manage project records.
- 👥 **Team Management** — Add and remove team member records.
- 💾 **Local Data Persistence** — Store tasks, projects, and team records using browser LocalStorage.
- 📱 **Responsive Design** — Adapt the interface to different screen sizes.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling, layouts, and responsive design |
| JavaScript | Application logic and interactivity |

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Visual Studio Code (recommended)

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd taskhive
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

4. Start creating and managing tasks.

## 💾 Data Storage

TaskHive uses browser LocalStorage to save application data between page refreshes. Data is stored locally in the browser and is not synchronized across different users or devices.

The current version is a frontend project and does not include a backend server, database, or production authentication system.
